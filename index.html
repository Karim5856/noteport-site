Send NotebookLM Studio Notes to Obsidian

NotePort is a Chrome extension that saves your Studio Notes straight into your Obsidian vault as Markdown, one note or a whole batch at a time.

Chrome Web Store listing coming soon

Free. Works with the Obsidian Local REST API plugin.

What NotePort does

Exports Studio Notes

Most NotebookLM tools export chat conversations. NotePort exports the notes you have saved in Studio.

Exports in batches

Pick several notes and send them all to your vault in one go.

Handles duplicates your way

When a note already exists in your vault, choose to replace it, append to it, or keep both as separate copies.

Keeps the source

Each note carries its platform, link, type and export time in the frontmatter, so you can always trace it back.

Set up

  1. Install NotePort from the Chrome Web Store.
  2. In Obsidian, install and enable the Local REST API plugin, then copy its API key.
  3. Open NotePort’s settings, paste the key, and test the connection.
  4. Open a notebook in NotebookLM, select your Studio Notes, and export.

Your notes stay on your computer

NotePort sends your notes from your browser to Obsidian running on your own machine. There is no NotePort server, no account, no analytics and no ads.
